About FloodWatch

A personal project built to help our community in Talisay City, Cebu stay informed and prepared during flood events.

Project

Barangay-Level Flood Early Warning System for Talisay City, Cebu

Talisay City, Cebu, Philippines · Devs: Knet & Tania · Built for our community

Abstract

Talisay City, Cebu faces recurrent flooding due to its unique dual vulnerability — upland terrain runoff from surrounding mountains and coastal storm surge exposure along the Tañon Strait. FloodWatch is a barangay-level flood early warning system using a Long Short-Term Memory (LSTM) neural network trained on PAGASA hourly rainfall data and DOST-FFWS river level records from 2015–2024. The model provides a prediction lead time of 3–6 hours, giving residents and local officials enough time to prepare or evacuate. The system runs as a web-based dashboard providing real-time alert classification across all 22 monitored barangays of Talisay City.

How we built it

01
Data collection
Hourly rainfall from PAGASA Mactan station and river level data from DOST-FFWS (2015–2024). Historical flood events validated using NDRRMC reports. Live operational data sourced from Open-Meteo (ECMWF/NOAA models, ~1 km resolution).
02
Preprocessing
Missing values handled via linear interpolation. Inputs normalized using Min-Max scaling (rain max: 200 mm/hr, water max: 5.0 m). Sliding 6-hour time windows created for model input sequences.
03
Flood prediction model
Gradient Boosting Classifier with isotonic probability calibration (CalibratedClassifierCV). Trained on 5,000 synthetic sequences spanning realistic Normal, Warning, and Critical flood scenarios. Will be retrained with real PAGASA sequences as data becomes available.
04
Alert classification
Predicted risk classified into three tiers based on water level and rainfall rate thresholds aligned with PAGASA advisory levels: Normal (<1.2 m, <25 mm/hr), Warning (1.2–2.0 m or 25–60 mm/hr), Critical (>2.0 m or >60 mm/hr).
05
Water level estimation
Where PAG-ASA gauge data is unavailable, water levels are estimated from 6-hour accumulated rainfall using a rational runoff method: WL = 0.3 m + 0.018 × R₆ (mm). Coefficient tuned to Talisay's coastal-upland terrain.
06
Web deployment
Frontend built with HTML, CSS, JavaScript, and Leaflet.js. Backend prediction model and data pipeline served via Python Flask API. Live rainfall refreshed every 15 minutes from Open-Meteo.

Note on live data: The dashboard uses Open-Meteo rainfall (real atmospheric model data) and estimates water levels via a rational runoff formula — the best publicly available data for Talisay at barangay resolution. PAG-ASA gauge and DOST-FFWS data will replace these estimates once formally requested and obtained. The POST /barangays/update API endpoint accepts direct gauge readings for override at any time.
